# 01 · Setup and Config

## Что изучено

- зачем нужен TypeScript: compile time vs runtime
- type erasure
- почему TS не валидирует данные из API
- tsconfig.json и strict
- явные return types

## Что я должен уметь

- объяснить, почему TS не проверяет данные из API, через type erasure
- настроить tsconfig.json со strict с нуля в новом проекте
- прочитать ошибку компилятора по коду TSxxxx и назвать причину до чтения текста
- написать функцию с типизированными параметрами и явным return type
- отличить тип функции `(x: number) => string` от типа её результата

## Файлы

- `01-first-types.ts` — первые типизированные функции + три класса ошибок компилятора

## Сложные моменты

- TS18003 — читал ошибку и не понял, хотя в тексте дословно написано No inputs were found
- npm tsc --v вместо npx tsc --version — получил версию npm и принял за версию TypeScript
- функция без скобок ≠ вызов: `formatRating` имеет тип `(rating: number) => string`,
  `formatRating(8)` имеет тип `string`
- как TS встраивается в проект: tsconfig + npm run check + запуск через npx tsx, без сборки в JS

## Notes

- TS2345 — аргумент не того типа, что объявлен у параметра
- TS2554 — неверное количество аргументов
- TS2322 — присваивание значения не того типа
- TS18003 — не найдено ни одного .ts файла по путям из include
- запуск файла: `npx tsx <path>` · проверка типов: `npm run check`
